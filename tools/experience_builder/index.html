rocket_launch Export to BHR runtime

Exports the current project to export/generated/ — the runtime's default scenes root (py -3.12 main.py runs it directly). The project is saved to BHR_Experience.bhrx.json first, so the file on disk always matches what was exported.


      

      

        
The project file has been saved. To generate the runtime tree (per-scene
        metadata.json + sequence.json + extracted frames), run this from the
        repo root:

        py -3.12 scripts/export_experience.py "project.bhrx.json"
        
Output goes to export/generated/ — the runtime's default scenes root
        (py -3.12 main.py runs it directly). Add --no-frames to skip ffmpeg
        frame extraction and only write metadata (fast; good for a first look).

        
Tip: run py -3.12 scripts/builder_server.py in a
        terminal and this dialog gains a one-click Run export button.

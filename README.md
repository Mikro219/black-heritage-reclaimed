# Black Heritage Reclaimed

A gesture- and voice-controlled installation that retells the journey of
freedom-seekers along the Underground Railroad to the Queen's Bush settlement
in Wellington County, Ontario. Visitors stand in front of a projected display
and move the story forward with hand gestures and spoken keywords — no
controllers, no touchscreen.

Built for the Guelph Black Heritage Society by Messam Multimedia.

## How the project fits together

**`BHR_Experience.bhrx.json` is the single source of truth.** The experience
is authored in the browser-based Experience Builder, exported into a runtime
tree, and played from there:

```
assets/video/BHR Draft 1.mp4       master animation draft (delivered)
assets/audio/                      stems, CapCut timeline, voice lines
        │
        ▼
tools/experience_builder/          author blocks, choices, interaction
  (edits BHR_Experience.bhrx.json)   windows, audio lanes, captions
        │
        ▼
scripts/export_experience.py       .bhrx  ->  export/generated/
        │                            (sequence.json + scenes/scene_NN/
        ▼                             frames, metadata, audio)
main.py                            plays export/generated by default
        │
        ▼
scripts/build_exe.py               packages everything into dist/BHR/BHR.exe
                                   (re-runs the export first — the build can
                                    never drift from the .bhrx)
```

There is no hand-edited scenes tree anymore — to change the experience, edit
the `.bhrx` in the builder and re-export. A metadata-only re-export
(`--no-frames`) is fast; frames re-extract only when the source video changes.

## Getting started (developers)

### Prerequisites

- **Python 3.12** (Windows: `py -3.12`) — [python.org/downloads](https://www.python.org/downloads/)
- **ffmpeg** on PATH (frame/audio extraction): `winget install ffmpeg`
- A USB webcam (the exhibition rig uses an Orbbec Gemini 335 depth camera —
  the code falls back to any webcam automatically)
- A microphone for the voice commands

### Setup

```bash
git clone <repo-url>
cd BHR
python -m venv .venv
.venv\Scripts\activate            # Windows   (source .venv/bin/activate elsewhere)
pip install -r requirements.txt
py -3.12 scripts/setup_voice.py   # downloads the Vosk voice model (~50 MB)
```

### Export and run

```bash
py -3.12 scripts/export_experience.py BHR_Experience.bhrx.json   # build export/generated
py -3.12 main.py                                                 # run it
```

Useful flags: `--dry-run` (walk every shot with no hardware), `--start-shot NN`
(jump to an original master-timeline shot — see `docs/START_SHOT_MAPPING.txt`),
`--scenes DIR` (alternate tree), `--prewarm` (pre-build the frame cache).

### Keys and voice commands

| Key | Action |
|-----|--------|
| `Space` | pause / play (the app boots paused) |
| `S` | skip prologue / tutorial / epilogue |
| `R` | restart from the beginning (lands on the paused boot screen) |
| `C` | captions on/off |
| `F` | fullscreen |
| `D` | debug overlay |
| `K` | skeleton mini-panel |
| `Enter` | confirm camera-setup screen |
| `↑` / `↓` | volume (while paused) |
| `Esc` | quit |

Say **"skip"** during the tutorial, prologue or epilogue to skip it; say
**"ready"** on the camera-setup screen to confirm. When the experience ends it
pauses and loops back for the next visitor (`config.json "end_loop"`).

## Authoring the experience

Open `tools/experience_builder/index.html` in Chrome/Edge — no install, no
build step. Run `py -3.12 scripts/builder_server.py` alongside it and the
builder's Export button runs the exporter itself (streamed live into the
dialog); without it the dialog shows the command to run by hand. Import the master MP4, carve it into playback/choice blocks on the
node canvas, drag interaction windows onto each block's timeline, lay out
audio (VO/music/ambience/SFX lanes) and captions, preview with simulated
detections, then export. See
[`tools/experience_builder/README.md`](./tools/experience_builder/README.md)
for the full tour and how blocks map to runtime shots.

After an export with fresh frames, prewarm the frame cache so first plays
don't stutter (packs are raw RGB — mind the disk budget; shot 01 and the
choice shots matter most):

```bash
py -3.12 scripts/prewarm_frame_cache.py --shots 01,02,03,04,09,10,12
```

## Project layout

```
main.py                  boot, key handling, main loop
config.json              every tunable value, incl. the per-machine "host"
                         section (camera/mic/display/performance + tuning)
BHR_Experience.bhrx.json the experience definition (single source of truth)
engines/
  shot_sequence_player   the runtime spine: shot FSMs, holds, branching
  sequence_loader        export/generated sequence.json + per-scene metadata -> Shot objects
  render_engine          frame playback, hand-icon cursors, captions, pause menu, tutorial cards
  gesture_engine         camera + MediaPipe Pose thread (pose-only), detector dispatch, depth fusion
  voice_engine           Vosk keyword spotting + hum/whisper DSP
  audio_mixer            layered stem audio: looping beds + frame-anchored SFX/VO (audio_events)
  narration_adapter      plays a shot's AL-XX-YYY audio lines
  tutorial_engine        code-rendered tutorial at start
  palette                the project colour palette (player-facing UI)
  event_bus, frame_cache plumbing
  depth/                 Orbbec Gemini 335 adapter + depth fusion
  detectors/rules/       one file per gesture detector (+ shared pose_helpers.py)
scripts/                 export_experience (.bhrx -> runtime tree), build_exe,
                         prewarm_frame_cache, capcut_audio (CapCut draft ->
                         audio lanes), build_captions / align_captions,
                         gesture_tuner / voice_tuner, setup_voice, misc pipeline
tools/experience_builder/  browser flow editor (see its README)
tests/                   regression suite (see below)
export/generated/        the generated runtime tree (gitignored — re-exportable)
assets/                  master video, audio stems, hand icons, docs (gitignored
                         except what was already tracked)
models/                  Vosk model (downloaded by setup_voice.py)
```

## Running the tests

Run the regression suite after **any** engine or detector change — it encodes
the playtest behaviour contract for every interaction, the depth-fusion rules,
tutorial flow, render/audio timing, and the exporter's wiring invariants:

```bash
py -3.12 -m unittest discover -s tests
```

~250 tests, under a minute, no camera or display needed. If a test goes red, an
interaction regressed — fix the code, not the test (tests only change when the
intended behaviour changes).

## Configuration and tuning

Everything tunable lives in `config.json` — no magic numbers in code:

- **Top level** — resolution, Orbbec on/off, tutorial/captions toggles,
  detection thresholds, timing profiles, the Vosk keyword grammar, depth
  player band, and `master_audio_offset_ms` (lip-sync trim for the baked
  master-audio shots; per-shot overrides available).
- **`"host"` section** — the per-machine hardware binding: camera, microphone,
  display, performance, plus the tuners' saved `gesture_tuning` /
  `voice_tuning` values. Edit this on each deployed machine (the exhibition
  values are noted in the `//host` comment block).

On-site: run `py -3.12 scripts/gesture_tuner.py` and
`py -3.12 scripts/voice_tuner.py` to tune detectors live (saved into the
`"host"` section), and flip `debug_overlay` on while calibrating.

## Audio

Each scene's `metadata.json` carries an `audio_events` list — music/ambience
beds loop through interaction holds and hand over across shots, SFX and
Auntie Liza's VO are frame-anchored one-shots — mixed by
`engines/audio_mixer.py` from the export's `_audio/` pool. The timeline was
imported from the CapCut master draft (`scripts/capcut_audio.py`) and is
edited in the builder's audio lanes. Five linear stretch shots instead play a
baked whole-file master mix, trimmed live by `master_audio_offset_ms`.
Captions were seeded from the script PDF and speech-aligned with Vosk
(`scripts/align_captions.py`); edit them in the builder's captions lane.

## Packaging for the exhibition PC

```bash
py -3.12 scripts/build_exe.py --keep-packs
```

Re-exports the `.bhrx`, builds `dist/BHR/BHR.exe` with PyInstaller, and stages
config + the generated tree next to it. `--keep-packs` preserves prewarmed
frame caches across rebuilds. See [`docs/packaging.md`](./docs/packaging.md)
for deployment and [`docs/HOW_TO_RUN.md`](./docs/HOW_TO_RUN.md) for the
non-technical operator guide.
